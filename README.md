# ISM3232 - Module 2: zsh Navigation and File Operations

## Commands Practiced

| Command        | What it does                            |
|----------------|-----------------------------------------|
| pwd            | Prints the current working directory    |
| ls             | Lists visible files and folders         |
| ls -la         | Lists all files including hidden ones   |
| cp             | Copy a file                             |
| mv             | Move or rename a file                   | 
| cat            | Print contents of file to the terminal  |
| rm             | Removes and permanently deletes a file  |
| code .         | Open current folder as VS Code Workspace|

## Week 3: Virtual Environments and .zshrc

| Command                       | What it does                               |
|-------------------------------|--------------------------------------------|
| python3 -m venv .venv         | creates a virtual environment folder       |
| source .venv/bin/activate     | activates the virtual environment          |
| deactivate.                   | exits the virtual environment              |
| pip list                      | shows installed packages                   |
| pip freeze > requirements.txt | saves installed packages to a file         |
| ll                            | alias for 'ls -la'                         |
| c                             | alias for 'clear'                          |
| py                            | alias for 'python3'                        |
